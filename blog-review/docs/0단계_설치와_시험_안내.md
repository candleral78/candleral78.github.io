# 블로그 검수 도구 0단계 — 설치와 시험 안내

0단계는 "구글 서버에서 네이버 자료를 실제로 읽을 수 있는지" 확인하는 시험입니다.
화면은 아직 없고, 구글 시트에 결과표가 생깁니다. 블로그 글쓰기 앱과는 완전히 따로 만듭니다.

## 1. 새 구글 시트 만들기 (1분)
1. 구글 드라이브에서 새 스프레드시트를 만들고 이름을 **블로그 검수 저장소**로 정합니다.
2. 주소창의 `https://docs.google.com/spreadsheets/d/` 다음부터 `/edit` 앞까지가 **시트 ID**입니다. 복사해 둡니다.

## 2. 새 Apps Script 프로젝트 만들기 (2분)
1. https://script.google.com 에서 **새 프로젝트**를 만들고 이름을 **블로그 검수 도구 서버**로 정합니다.
   (글쓰기 앱 서버 "블로그 글쓰기 앱 서버"에 붙여 넣지 않습니다.)
2. 처음 있는 `Code.gs` 내용을 모두 지우고, 저장소의 `blog-review/src/Code.gs` 내용을 통째로 붙여 넣은 뒤 저장합니다.

## 3. 스크립트 속성 넣기
왼쪽 톱니바퀴 **프로젝트 설정 → 스크립트 속성 → 속성 추가**

| 속성 | 값 | 필수 |
| --- | --- | --- |
| SHEET_ID | 1번에서 복사한 시트 ID (시트 메뉴 "확장 프로그램 > Apps Script"로 만들었으면 넣지 않아도 됨) | 선택 |
| ADMIN_PW | 원하는 암호 | 화면을 쓸 때 |
| NAVER_CLIENT_ID | 네이버 개발자센터 Client ID | 5번 시험 |
| NAVER_CLIENT_SECRET | 네이버 개발자센터 Client Secret | 5번 시험 |
| SEARCHAD_API_KEY | 검색광고 API 액세스라이선스 | 6번 시험 |
| SEARCHAD_SECRET | 검색광고 API 비밀키 | 6번 시험 |
| SEARCHAD_CUSTOMER_ID | 검색광고 CUSTOMER_ID | 6번 시험 |

키가 아직 없으면 SHEET_ID와 ADMIN_PW만 넣고 시험해도 됩니다. API 시험 2개만 "건너뜀"으로 나옵니다.
키와 암호는 이 화면에만 넣습니다. 저장소나 대화창에는 적지 않습니다.

### 키 발급
- **네이버 개발자센터**: https://developers.naver.com → Application → 애플리케이션 등록 → 사용 API에서 **검색**과 **데이터랩(검색어트렌드)** 선택 → 환경은 **WEB 설정**, 서비스 URL은 `https://candleral78.github.io` → 등록 후 Client ID와 Client Secret 확인
- **네이버 검색광고**: https://searchad.naver.com 로그인 → 도구 → **API 사용 관리** → 네이버 검색광고 API 서비스 신청 → 액세스라이선스, 비밀키, CUSTOMER_ID 확인 (광고비를 쓰지 않아도 발급됩니다)

## 4. 시험 실행
1. 편집기 위쪽 함수 목록에서 **setup**을 고르고 **실행**을 누릅니다.
   처음에는 구글이 권한을 묻습니다. 계정 선택 → "고급" → "블로그 검수 도구 서버(안전하지 않음)로 이동" → 허용.
   (직접 만든 스크립트라 이렇게 나옵니다.)
2. 함수 목록에서 **runProbe**를 고르고 **실행**을 누릅니다. 30초 안팎 걸립니다.
3. 시트에 **probe** 탭이 생기고 시험마다 한 줄씩 기록됩니다. 아래 "실행 로그"에도 요약이 나옵니다.

## 5. 결과 보는 법
| 결과 | 뜻 |
| --- | --- |
| 성공 | 구글 서버에서 읽힘. 자동 검수에 쓸 수 있음 |
| 실패 | 구글 서버에서 막힘. 요약 칸의 이유를 Claude에게 전달 → 대체 방법(캡처 업로드 등)으로 설계 |
| 건너뜀 | 키가 없어서 시험하지 않음 |

시험이 끝나면 **probe 탭의 요약 칸(E열)을 복사해서 대화창에 붙여 주세요.** 그 결과로 1단계를 만듭니다.

## 시험 대상 바꾸기
`Code.gs` 위쪽 `PROBE_TARGET`에서 업체명, 플레이스 번호, 블로그 아이디, 글 번호, 키워드를 바꾸면 다른 업체로 시험합니다.

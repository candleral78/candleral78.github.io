# 블로그 공통 기준표 (글쓰기 앱 + 블로그 첨삭)

두 앱이 같은 기준으로 글을 쓰고 검수합니다. **두 앱의 규칙을 하나도 빼지 않고 모두 넣었습니다.**
기준을 바꿀 때는 이 표를 먼저 고치고, 두 앱에 같이 반영합니다.

- 글쓰기 앱: `blog-writer/src/app.html`의 `bodyPrompt()`(쓰는 규칙)와 자체 점검(12항목), `BANNED`, `AIPH`
- 블로그 첨삭: `blog-review/src/Code.gs`의 `STD`, `BANNED_WORDS`, `AI_PHRASES`, `machineChecks_()`, AI 첨삭 지시문

판정 구분: **꼭 고쳐 주세요**(수정 필요) / **권해 드려요**(권장) / **확인해 주세요**(추가 확인)
보는 때: **쓸 때**(원고에서 확인 가능) / **발행할 때**(대표님 체크리스트) / **발행 후**(링크로만 확인 가능)
